# Task 1 - Landing Page — Flowly

## Overview
A static landing page built for **Flowly**, a fictional focus/productivity app that helps
users protect deep-work sessions by silencing notifications and timing their focus blocks.
This project was built for **Level 1 – Task 1** of the Web Development & Design track under
the AICTE Oasis Infobyte Internship Program.

## Objective
Build a visually polished static landing page for a product, service, or brand, focusing on
foundational HTML/CSS layout skills.

## Tech Stack
- HTML5
- CSS3 (no JavaScript, as per task requirements)

## Features
- Sticky navigation bar with 3 links and a CTA button
- Hero section with headline, subheadline, CTA button, and a custom SVG "focus rings" visual
- Multiple content sections: Features, About, Testimonials, final CTA band
- Footer with contact/social placeholder links
- Consistent colour palette (mint / ink / teal / gold accent)
- Two typefaces used with a clear type scale (Fraunces for headings, Inter for body, IBM Plex Mono for labels)
- Fully responsive layout using CSS Grid and Flexbox — tested down to mobile widths
- Intentional spacing and box-sizing throughout — no element overlap

## How to View
1. Clone this repository or download the `index.html` file.
2. Open `index.html` in any modern web browser.

No build steps or dependencies required — it's a single static HTML file with embedded CSS.
