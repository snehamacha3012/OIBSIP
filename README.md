## Repository Structure
Each completed task is organized in its own folder using the format:
```
OIBSIP/[TrackName]-[Level/Task]-[ProjectName]/
```

Example:

```
OIBSIP/
├── WebDev-L1-LandingPage/
├── WebDev-L1-PortfolioWebsite/
└── WebDev-L1-TemperatureConverter/
```
Each task folder includes:
- Source code
- A `README.md` explaining the project
- Screenshots or output files (where applicable)
